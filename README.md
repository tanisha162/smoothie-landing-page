## 📌 Overview
An engaging, mobile-optimized promotional landing page crafted for an organic smoothie beverage brand. Incorporates energetic color palettes, nutritional ingredient breakdowns, customer social proof, and interactive flavor selection.

---

## 🚀 Getting Started

```bash
git clone https://github.com/tanisha162/smoothie-landing-page.git
cd smoothie-landing-page

npm install
npm run dev
```
